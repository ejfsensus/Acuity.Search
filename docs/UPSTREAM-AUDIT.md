## 3. Upstream Seam Audit & Adaptation Mapping

| Upstream Seam                                                            | Observed Upstream Behaviour                                                                                                                                                                | Acuity.Search Adaptation                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lib/tools/search.ts`                                                    | Uses single `SEARCH_API` (`tavily` default) or dedicated Brave (`type="general"`), with HTTP loopback to `/api/advanced-search` for `searxng` advanced mode                                | Routed through the unified server-side Acuity federation service (`lib/acuity/search/federate.ts`); preserves `CitationLabelAllocator` (`S1`, `S2`, ...) so citations never renumber during streaming                                                                                                                                                                                                                                     |
| `lib/tools/search/providers/searxng.ts`                                  | Hard-codes `engines=google,bing`, `time_range=year`, `safesearch=1` in basic mode; appends non-standard `&site=` query parameter; ignores `excludeDomains`; ignores `unresponsive_engines` | Rebuilt in `lib/acuity/search/providers/searxng.ts`: defaults to `safesearch=0` and all-time range, compiles single-host `site:` operands for strict scopes, enforces host/path scopes locally, supports server-side gateway headers (`ACUITY_SEARCH_SEARXNG_AUTH_HEADER` / `ACUITY_SEARCH_SEARXNG_AUTH_VALUE`), classifies HTTP 401/403 (JSON disabled), CAPTCHA/HTML pages, and `unresponsive_engines`, and preserves engine provenance |
| `lib/tools/search/providers/brave.ts`                                    | Accepts `includeDomains`/`excludeDomains` in signature but ignores them; passes `maxResults` directly without Brave's 20/page cap                                                          | Rebuilt in `lib/acuity/search/providers/brave.ts`: caps `count` at 20, supports `offset` page index (0..9), compiles safe `site:` operands, enforces local host/path post-filtering, and defaults to web search unless multimedia is requested                                                                                                                                                                                            |
| `lib/tools/search/providers/exa.ts`                                      | Calls `exa.searchAndContents` and reads `result.highlight \|\| result.text` (singular `highlight` property instead of `highlights` array)                                                  | Rebuilt in `lib/acuity/search/providers/exa.ts`: handles `highlights` array and `text`, passes native `includeDomains`/`excludeDomains`, preserves `author`/`publishedDate`, and enforces local host/path scope verification                                                                                                                                                                                                              |
| `lib/tools/search/providers/tavily.ts`                                   | Hard-codes `CLOUD_EXCLUDED_DOMAINS = ['instagram.com']`, requests `include_images: true` and `include_answers: true`                                                                       | Rebuilt in `lib/acuity/search/providers/tavily.ts`: removes opaque editorial exclusions, sets `include_answers: false` and `include_images: false` by default, passes domain scopes, enforcing local host/path checks, and never invokes Tavily when disabled or unconfigured                                                                                                                                                             |
| `app/api/advanced-search/route.ts`                                       | Unauthenticated route with substring domain matching (`domain.includes(d)`), raw query Redis cache keys, and `setInterval` memory cleanup                                                  | Consolidated with the Acuity federation, scope, budget, SSRF, and scoped cache-key rules                                                                                                                                                                                                                                                                                                                                                  |
| `lib/agents/researcher.ts` & `lib/agents/prompts/search-mode-prompts.ts` | Quick (20 steps) and Adaptive (50 steps) agent loops                                                                                                                                       | Integrated with Acuity epistemic integrity prompts (`lib/acuity/prompts/index.ts`), hard server-side request/extraction/latency budgets (`lib/acuity/search/budget.ts`), and provider-neutral LLM fallback (`results-only` when `ACUITY_SEARCH_LLM_MODE=unconfigured`)                                                                                                                                                                    |
| `lib/db/schema.ts`                                                       | Defines `chats`, `messages`, `parts`, `artifact_*`, `library_*`, `feedback` with RLS                                                                                                       | Extended via Drizzle schema and migration with `acuity_runs`, `acuity_provider_attempts`, `acuity_source_results`, `acuity_evidence`, `acuity_answer_versions`, `acuity_saved_research`, `acuity_shares`, `acuity_registry_revisions`, and `acuity_usage_reservations`                                                                                                                                                                    |
| `lib/auth/providers/none.ts` & `lib/auth/get-current-user.ts`            | Maps all unauthenticated visitors to a single shared `ANONYMOUS_USER_ID` (`anonymous-user`) when `ENABLE_AUTH=false`                                                                       | Isolated per-visitor signed guest session cookies in `lib/acuity/auth.ts`; blocks shared anonymous persistence in public multi-user production                                                                                                                                                                                                                                                                                            |
| `components/chat-share.tsx` & `lib/actions/chat.ts`                      | Immediately flips `chat.visibility = 'public'` for the entire conversation                                                                                                                 | Replaced with selected-output Share Preview modal and immutable `acuity_shares` snapshots (`/share/[token]`) with hashed tokens, optional expiry, and instant revocation                                                                                                                                                                                                                                                                  |
| `docker-compose.yaml`                                                    | Bundles a local `searxng/searxng:latest` service and sets `ENABLE_AUTH=false` with shared `ANONYMOUS_USER_ID`                                                                              | Removed bundled SearXNG service dependency; configured external `SEARXNG_API_URL`, PostgreSQL, and Redis with health checks and isolated session defaults                                                                                                                                                                                                                                                                                 |
